# 财务岗位聚合（个人本地工具）

每天自动抓取 **猎聘 / 前程无忧 51job / 智联招聘 / BOSS直聘**（上海 · 财务方向）的公开岗位，
聚合到本地数据库，在本地网页里筛选、比较、一键跳转原文。

> 仅供个人求职浏览使用，不分发、不对外建站。每天每平台只有十几次慢速搜索请求，
> 岗位详情一律跳转原网站查看。

## 快速开始

| 想做什么 | 怎么做 |
|---|---|
| 浏览岗位 | 双击 `start_ui.bat`（浏览器自动打开本地页面） |
| 立即抓一轮 | 网页右上角「🫙 立即抓取」按钮，或命令行 `python run_fetch.py` |
| 只跑某个平台 | `python run_fetch.py --platform liepin zhaopin` |
| 调试（每组只试 1 个关键词） | `python run_fetch.py --limit-keywords 1` |
| 每天自动抓 | 见下方「定时抓取」 |

## 改关键词 / 城市 / 平台

所有配置都在 **`config.yaml`**：关键词组、平台开关、抓取频率。改完即生效，无需改代码。
城市目前内置上海（各平台城市码写死在各抓取器文件里，换城市时改对应文件顶部的
`city_codes`，可用 `scripts/discover_liepin_dq.py` / `scripts/calibrate_zhaopin.py` 查码）。

## 定时抓取（Windows 任务计划，每天 09:30）

1. 右键 `scripts\register_task.ps1` →「使用 PowerShell 运行」（错过开机会在开机后补跑）
2. 想取消：运行 `scripts\unregister_task.ps1`

## 平台说明

| 平台 | 方式 | 登录 |
|---|---|---|
| 猎聘 | 拦截页面自身的搜索接口 | 不需要 |
| 前程无忧 | 拦截 search-pc 接口 | 不需要 |
| 智联招聘 | 解析搜索页内嵌数据（薪资是真值） | 不需要 |
| BOSS直聘 | 真实 Chrome + 登录态复用（详见下） | **需要本人登录一次** |

### BOSS直聘说明

- 首次使用：命令行运行 `python scripts/login_zhipin.py`，在弹出的真实 Chrome 里
  **本人**登录一次（扫码/验证码），登录态会长期保留在独立目录
  `data/browser_profile_chrome/`（与日常浏览器完全隔离）
- 每日抓取自动复用该登录态；BOSS 反爬最严，抓取策略也最保守：
  每关键词只搜第 1 页、重试最多 1 次、出现验证立即跳过该平台绝不硬闯
- 登录失效时网页顶部 BOSS 胶囊会变锁，重新跑一次 login_zhipin.py 即可，
  其他平台不受影响

出现验证码 / 登录失效时：抓取会自动跳过该平台并继续其他平台，网页顶部该平台
胶囊会变红/加锁，按提示重新登录即可，不影响已入库数据。

## 数据规则

- 同一岗位（平台 + 站内岗位 ID）只存一条，每次抓到刷新「最近抓到」时间
- 连续约一周（7 轮）没再出现的岗位自动归档，默认只在 UI 显示在招岗位
- 归档超过 180 天的记录自动清理
- 日志在 `logs\fetch_年月日.log`，出问题先看这里

## 目录结构

```
config.yaml        # 唯一配置入口（关键词组/城市/平台/频率）
run_fetch.py       # 抓取入口（手动 / 定时任务 / UI 按钮共用）
app.py             # 本地网页（Streamlit）
start_ui.bat       # 双击启动网页
jobaggregator\     # 核心代码（db / 抓取插件 / 编排）
scripts\           # 定时任务注册、接口校准等工具
data\jobs.db       # 岗位数据库（SQLite）
logs\              # 运行日志
```
